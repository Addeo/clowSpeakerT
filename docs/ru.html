2. Назначение приложения

ClowTalker помогает создавать и управлять задачами с помощью голосового ввода и Siri/App Intents. Дополнительные интеграции могут отправлять текст задач в сторонние сервисы по вашей настройке (например, Telegram Bot API или пользовательский HTTPS-эндпоинт).
